# Jerry “J5” Wright — Official EPK

GitHub Pages-ready electronic press kit for Jerry “J5” Wright and the album **We Make Alot of Noise**, releasing September 11, 2026.

## Publish with GitHub Pages

1. Upload every file and the `assets` folder to the root of the GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then click **Save**.

Keep the filenames and folder structure unchanged so the artwork and songs load correctly.
